## Prepare the editable project

1. Bind exact raw video/script/project/revision. Preserve originals/manual edits,
   hashes, transcript/cut map, raw-to-edited clocks and checkpoints. Keep outputs,
   projects, previews, assets and managed caches on D: under the job's Premiere,
   After Effects, Smart Visuals and audio folders. Do not select an old demo source.
2. Use existing **Smart Clean** for silence and retakes. Prefer the second/later
   complete usable take, preserving unique speech, quiet words and intentional
   pauses. A later false start is not a better take. Script guides meaning and
   spelling, never fabricated speech/timing. **Smart Edit is exceptional**, only
   on owner request or a concrete edit need; do not routinely restructure.
3. Prefer **editable Premiere Pro zoom-in/out keyframes**, appropriate Ease In/Out
   or Bezier interpolation, stable framing and exact edited speech/cut timing.
   Choose **Hyperframes OR Remotion** for motion that benefits from it, minimizing
   full-video exports. Prefer native handoffs, transparent overlays or section
   renders; do not bake the presenter just to add zooms or run both graphics tools.
4. Add **licensed documentary background music**: suspense, thriller, tension,
   build, impact/attention passages selected for the story, plus relevant real SFX.
   Create matching disk folders AND Premiere bins **Background Music** and
   **Sound Effects**, with **Chosen** and **Alternatives**. Import useful options;
   place only selected cues, keeping dialogue/music/SFX separately editable.
   Apply the owner's actual Premiere speech-enhancement preset to dialogue ONCE
   when supplied. Its name/screenshot remains pending: do not invent settings or
   claim application while missing. Retain actual music licence/credit evidence.
5. Use existing **Smart Visuals**, **NOT B-roll**. Identify player/team/year/event
   from script AND actual edited speech. Source historically matching photos and
   verify identity, kit/season/year/context with evidence. Arrange numbered scene
   folders in narration order with edited timecodes, sources/rights/date evidence
   and alternatives for owner selection. Label unverified dates or illustrative
   substitutions rather than presenting recent photos as historical evidence.
6. Use real **Premiere–AE Dynamic Link** where supported. Check exact sequence/
   composition, cuts, audio and effects. Preserve the one-visible-editor RAM
   policy: save/release one UI before the next; Link background processes use RAM.
   If unsupported, report the dependency and preserve editable project/cut map;
   never call a flattened export Dynamic Link.
7. In AE, use existing **Import Template** for up to **TWENTY preferred shuffled
   usable packages**, then existing **Template Aliner** over the edited video.
   Preserve canonical bins, source comps/fonts/expressions/private editable graphs
   and owner video/audio. Persist shuffled selection/order, batch and instance IDs;
   retries resume rather than importing twenty more or reshuffling. Use each
   eligible template once, trim final end, report uncovered tail/shortfall rather
   than silently repeating/stretching. Add a neutral **top, full-duration
   adjustment layer** for the owner's manual grade.
8. **STOP at native editable AE handoff. DO NOT run Template Text, hide template
   text, replace wording or auto-fill headings.** Owner changes positions/durations,
   finishes manually, later runs Template Text and exports. Preserve all those
   edits on resume. Provide actual native preview/screenshots, project/media-map
   paths and material font/media/expression/coverage limitations. Do not add
   Talking Head auto captions or automatic Resolve grading to this workflow.
