HINGLISH EDITOR - EASY START

STANDALONE APP
1. Double-click Run Hinglish Editor.bat
2. Smart Clean = remove silence without script
3. Script Edit = arrange videos by script meaning
4. Auto Captions = animated Roman Hinglish captions
5. Optional: paste your rough script under Reference script. It corrects likely spellings and names without forcing every spoken line to match.
6. Click Choose videos or Choose folder, select one of the 14 styles and CPU/NVIDIA RTX, then click the orange button
7. When complete, click Review result, then open a video.
8. Caption Studio lets you edit every caption, template, font, vertical position, size, and 9:16 / 1:1 / 16:9 format.
9. Click Save & rebuild. It updates the caption layer, SRT, ASS, transcript and XML.
10. Import CAPTIONED_SEQUENCE.xml into Premiere/Resolve

PREMIERE PRO 2024
1. Double-click Install Editor Plugins.bat once, then restart Premiere
2. Open Window > Extensions > Hinglish Editor
3. Select video clips
4. Click Smart Clean, Script Edit or Auto Captions
5. For captions, paste an optional spelling-reference script and choose one of the 15 premium styles, including Typography 1
6. The new editable sequence is imported automatically

DAVINCI RESOLVE STUDIO
1. Double-click Install Editor Plugins.bat once, then restart Resolve
2. Open Workspace > Scripts > Hinglish Editor
3. Run the edit
4. Click Import to Resolve

AUTO CAPTION OUTPUT
- CAPTIONED_SEQUENCE.xml = source video plus transparent animated caption layer
- captions.srt = editable Roman Hinglish subtitles
- captions.ass = styled editable subtitle file
- transcript.txt = Roman Hinglish transcript
- report.html = on-video Caption Studio for manual text, style, position, size and format changes
- Original video and audio are unchanged

ADD B-ROLL (NEW)
First time only:
1. Double-click Run Hinglish Editor.bat -> Add B-roll -> B-roll settings
2. Paste your Pexels key and Pixabay key, and/or add folders of your own clips -> Save settings
Every time:
- Premiere: open your edited sequence -> Hinglish Editor panel -> Add B-roll -> Add B-roll to the open sequence
- Resolve Studio: open the timeline -> Workspace > Scripts > Hinglish Editor -> Add B-roll -> run -> Import to Resolve
- App: choose a video (or a timeline XML) -> Add B-roll
Result: new sequence NAME_BROLL with B-roll on V2. Open Review result to swap/remove clips, then Save & rebuild.
Reels get quick 1.5-3 s cutaways; long YouTube videos get 3-6 s cutaways every ~20-40 s.

SMART ZOOM (NEW)
- Premiere: open your edited sequence -> Hinglish Editor panel -> Smart Zoom -> choose Style / Strength / How often -> run
- Resolve Studio: open the timeline -> Workspace > Scripts > Hinglish Editor -> Smart Zoom -> run -> Import to Resolve
- App: choose a video (or a timeline XML) -> Smart Zoom -> Add smart zooms
Result: new sequence NAME_ZOOM. Zooms land on the stressed word, go into your face, ease in/out smoothly.
Audio is never cut. Review result shows every zoom plus a preview video.

OLD / UNSUPPORTED / MODIFIED EDITORS
Use the standalone app. Import the generated XML manually.

YOUR ORIGINAL VIDEOS AND OLD TIMELINE ARE NEVER DELETED.
