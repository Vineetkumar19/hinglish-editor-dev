script -> image queries -> web/Agent Reach/Wikipedia/stock -> local Vision ->

float movement. PNGs and photos are local layers; their provenance stays in the
project. Objects search the web first in combined mode, then may use the existing
image generator. Named people/brands/places must occur in the source script.

are delegated to the local model. Existing clip-based templates remain available.
