One-time setup

Install the included Storylens Local Publisher extension in the Chrome profile where you use Instagram.

  1. Open Chrome’s extensions page, then enable Developer mode.
  2. Choose Load unpacked and select this folder:

editor_plugins/storylens-chrome

Native input uses Chrome’s page debugger permission, which can inspect and control browser tabs. The code attaches to its dedicated Instagram tab for the selected MP4, or its optional YouTube Studio tab for reviewed release dates, then detaches. It does not request Windows administrator access or read passwords/cookies.

Open its toolbar popup. Paste the connection code below, leave port 8765, then choose Connect & check for tasks.

YouTube upload and scheduling

For an existing installation, reload Storylens Local Publisher 0.4.0 once in Chrome's extensions page. In its popup choose Enable YouTube Studio scheduling and approve the optional Studio site access. This access persists until you remove it in Chrome.

Storylens uploads your reviewed campaign exports first, then schedules only their returned YouTube IDs using one Studio tab. The editor verifies the exact release dates before reporting success. Keep Chrome and Storylens open until verification finishes.

Keep the code private. It permits only the bounded local browser work queue; it is not the editor’s full control key.
