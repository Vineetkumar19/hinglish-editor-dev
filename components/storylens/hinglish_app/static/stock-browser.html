One-time setup

  1. In Chrome, open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked and select:editor_plugins/storylens-stock-chrome
  3. Open Storylens Stock Search from Chrome’s extensions menu. Click Connect and approve access to Pexels and Pixabay.

The popup opens this page in Chrome. Then pair it below.

Existing B-roll sources stay available while Chrome is disconnected.

Access details

This separate extension searches public video pages in its own tabs. It can read and interact with Pexels and Pixabay pages after you enable site access. It returns public video links and dimensions to this local editor. It does not use API keys, local Vision, browser debugging or cookie access. Complete any website verification yourself.

No publishing permissions are added. Keep Chrome and Storylens running while collecting videos.
