## External limits found during the real test

- DuckDuckGo initially returned usable results, then explicitly reported an outage. Bing returned unrelated brand pages; Brave returned HTTP 429, Yahoo web search HTTP 500, and Google's fetched search page exposed no usable results. No challenges or access restrictions were bypassed.
- Product recovery reused the exact successful public-search discoveries captured earlier in this audit. Those links were imported into the new persistent search cache, with original timestamps and provenance. Product pages were fetched again for the displayed prices. This demonstrates recovery for previously discovered items; it does **not** prove reliable discovery of every unseen product during a search outage.
- Known useful links are cached. Unknown/new items can still show partial results, a market-search link, or accept an exact public listing URL. No universal free-search availability promise is made.
- MDcomputers returned HTTP 403. The app reports that source failure while other retailers supply observations. Amazon/Flipkart links were discovered; automatic price extraction from every Amazon/Flipkart page is not claimed.
- Card benefits and rates require accessible issuer pages. Unsupported issuers show partial/unknown details. A published issuer maximum rate is not a personalized APR. Exact payment deadlines, minimum due and balances require the user's statement.
- Digital-gold provider redemption values, arbitrary bonds/schemes, automated bank reconciliation, a complete corporate-events calendar, Windows push/SMS and actual-phone LAN connectivity remain outside the verified routes. Existing manual dated values remain available.
- Qwen is connected to retrieved data; no fine-tuning occurred. It explains observations and cannot modify the ledger. Context is bounded and prioritizes records relevant to the question; it does not contain every fact on the internet.

## Implementation and checks

- Added instrument-name search, automatic per-record enrichment, persisted status, bounded concurrency, timestamped source evidence, retry controls and public-search caching.
- Added structured INR Product/Vehicle offer extraction with model/capacity matching. Public fetches reject private destinations, credentials, non-HTTPS schemes and oversized responses, including redirected URLs.
- Source failures do not substitute zero for unknown quotes or turn retail references into resale assets. Research does not resurrect deleted records; changed identities discard mismatched evidence.
- Added card/product panels and product topics to automatic news. Corrected false benefit titles, irrelevant product stories, duplicate headlines, bank context and excessively strict volatility suppression.
- Kept the glass design, checked desktop/mobile screenshots, and removed avoidable dashboard stretching. Layout inspector initially reported zero failures and three warnings; the spacing/density warnings led to the final grid adjustment. Some full sections intentionally continue below the fold. Colored allocation marks are not heavy panel outlines.
- Production TypeScript/Vite build passed. **74 automated accounting/API/source regression checks passed**. Initial sandbox-only local-HTTP EACCES failures disappeared when the tests ran with authorized local network access.
- Independently summed the live investment, cash, FD and asset totals less debt: **INR 746,085.10**, matching the demo UI. Confirmed invalid-symbol recovery, news deduplication, dashboard settings, benchmark history and the untouched empty personal ledger.
